Getting started

What do I need?

Python 3.10 or newer, git, uv, a Modal account, and an API key for your model. Compute is billed to your Modal account and model calls to your API key.

How do I install it?

git clone --recurse-submodules https://github.com/{{ repository }}.git
cd cua-speed-run
uv venv --python 3.11
source .venv/bin/activate
uv pip install -e .
cua-speedrun install
modal token new

modal token new connects your Modal account. Run all later commands from the cua-speed-run folder.

How do I run my first evaluation?

Add your key to a .env file in that folder, for example OPENAI_API_KEY=sk-..., and run an included agent on five OSWorld tasks:

cua-speedrun run --remote \
  --submission templates/codex_cli \
  --benchmark osworld-mini

It prints each task's score and time, and the folder where the run is saved.

Evaluate a model

How do I evaluate my model?

Write an agent that calls your model, or adapt one of the included templates. Then run it on the leaderboard's task sets:

cua-speedrun run --remote \
  --submission path/to/your-agent \
  --benchmark osworld-energy50-representative

Which task sets are on the leaderboard?

  • OSWorld, 50 tasks: osworld-energy50-representative
  • OSWorld 2.0, 52 tasks: osworld2-k52
  • CUA-World, 26 tasks: cua-world-long-k26
  • MyPCBench, 38 tasks: mypcbench-energy38

OSWorld 2.0 is gated: request access to its tasks and its assets on Hugging Face, then run hf auth login. CUA-World and MyPCBench are graded by Gemini, so also add GEMINI_API_KEY to your .env.

Open-weight models

How do I evaluate an open-weight model?

Start your model server in init.py and request a GPU with --gpu. The qwen3vl template already does this with vLLM. Set VLLM_MODEL to your model:

VLLM_MODEL=your-org/your-model cua-speedrun run --remote \
  --submission templates/qwen3vl \
  --benchmark osworld-energy50-representative \
  --gpu L40S --env VLLM_MODEL

The leaderboard uses an L40S. Use a larger GPU, such as H200, if your model does not fit. The first run downloads the model, so it takes longer. For a private model, also add --env HF_TOKEN.

Build an agent

What does an agent look like?

A folder with two Python files:

agent.pytimed, once per task
Looks at the screen, sends actions, and calls done.
init.pyuntimed, before tasks
Installs packages or starts a model server. It may run more than once, so it must be safe to repeat.

A complete agent.py, apart from your model call:

import sys
from cua_speedrun.client import Computer

computer = Computer(sys.argv[1])
instruction = sys.argv[2]

while True:
    screenshot = computer.observe()["png"]  # PNG bytes
    actions = my_model(instruction, screenshot)  # your code
    if not actions:
        break
    computer.step(actions)

computer.done()

Run it with --submission path/to/your-agent.

What actions can it send?

step takes a list of actions. Sending several at once saves round trips. Coordinates are screen pixels.

{"mouse": {"left_click": [640, 400]}}
{"mouse": {"double_click": [640, 400]}}
{"mouse": {"right_click": [640, 400]}}
{"mouse": {"move": [640, 400]}}
{"mouse": {"left_click_drag": [[100, 100], [300, 300]]}}
{"mouse": {"scroll": 3}}                  # positive scrolls down
{"keyboard": {"text": "hello"}}
{"keyboard": {"keys": ["ctrl", "s"]}}     # pressed together
{"action": "wait", "time": 1.0}

How do I pass API keys and settings?

Put them in .env. Variables ending in _API_KEY reach your agent automatically. Pass any other variable with --env NAME.

How do I report model cost?

After each model response, print the task's running total in this format:

__CUA_SPEEDRUN_COST_V1__{"cost_usd": 0.1234}

What can my agent access?

The internet, and the desktop through observe, step, and done. It cannot reset the desktop, open a shell in it, or see how tasks are graded.

Add a benchmark

How do I add my benchmark?

Package your tasks as a Gym-Anything environment, where each task has an instruction, a setup script, and a verifier. Then list the tasks in a benchmark folder:

# benchmarks/my-benchmark/manifest.yaml
name: my-benchmark
version: "0.1"
tasks:
  - tasks/first_task

# benchmarks/my-benchmark/tasks/first_task/task.yaml
task_id: my_first_task
description: Short label for this task
timeout_sec: 600
env:
  kind: gym-anything
  env_dir: path/to/your/environment
  task_id: first_task

Run any agent on it with --benchmark benchmarks/my-benchmark. To add it to the leaderboard, {{ contact() }}.

Can I run fewer tasks?

Yes. From your past model-by-task scores, this picks a smaller subset whose scores track the full benchmark:

python scripts/select_representative_tasks.py scores.json --output selection.json

Without Modal

I don't have a Modal account.

Create one at modal.com, then run modal token new.

Can I run without Modal?

Yes, on a Linux machine with KVM. Give your user KVM access, log out and back in, and run without --remote:

sudo usermod -aG kvm "$USER"
cua-speedrun install
cua-speedrun run \
  --submission path/to/your-agent \
  --benchmark osworld-energy50-representative

Leaderboard results were measured on Modal, so use Modal to compare with them.

Results and data

What exactly is timed?

From the moment the agent receives the instruction until it calls done or reaches the time limit. Setup, init.py, and grading are not timed.

How are score and cost calculated?

The score comes from the benchmark's own verifier, averaged over the task set. The cost is the model API cost per task. It does not include Modal compute.

Where are my results saved?

In the folder printed at the end of the run. It holds a summary and, for each task, every screenshot, action, and verdict.

Where can I get the leaderboard data?

Download the results as a CSV from the leaderboard. Full trajectories are on Hugging Face.

The leaderboard

How do I get my result on the leaderboard?

Run the leaderboard's task sets, then {{ contact() }}. Include the zipped run folder and your agent's files.

When something fails

A run failed. What should I check?

Open the run folder. events.jsonl lists what happened, and each task's folder has your agent's output. Rerun one task with --task TASK_ID.

Where do I report a bug?

Open an issue on GitHub with the command you ran and the error.
