Getting started

What do I need?

Python 3.10 or newer, a Modal account, and an API key for your model. Modal runs the desktops and your agent, and bills your account. No Modal? You can also run on your own machine.

How do I run my first evaluation?

pip install cua-speedrun
cua-speedrun setup
cua-speedrun benchmark

setup saves your Modal credentials and API keys. benchmark asks for an agent and a task set, then shows progress while it runs.

How do I skip the questions?

Name the agent and task set. cua-speedrun catalog lists them all.

cua-speedrun benchmark --agent claude --dataset osworld-50

Can I close my laptop while it runs?

Yes. Add --host modal and the evaluation runs from your Modal account. Check on it later with cua-speedrun status RUN_ID.

Evaluate a model

How do I evaluate my model?

Write an agent that calls your model, or adapt one of the included agents. Check it, then run it:

cua-speedrun validate --agent ./my-agent
cua-speedrun benchmark --agent ./my-agent --dataset osworld-50

Which task sets are on the leaderboard?

  • OSWorld, 50 tasks: osworld-50
  • OSWorld 2.0, 52 tasks: osworld2-52
  • CUA-World, 26 tasks: cua-world-26
  • MyPCBench, 38 tasks: my-pc-bench

OSWorld 2.0 is gated: request access to its tasks and its assets on Hugging Face, then run hf auth login. CUA-World is graded with GEMINI_API_KEY and MyPCBench with MYPCBENCH_JUDGE_API_KEY, so add those keys in setup.

Open-weight models

How do I evaluate an open-weight model?

Start your model server in init.py and name a GPU in agent.json, such as "gpu": "L40S". The included qwen3vl agent does this with vLLM:

VLLM_MODEL=your-org/your-model cua-speedrun benchmark \
  --agent qwen3vl --dataset osworld-50 --env VLLM_MODEL

Use --gpu H200 if your model does not fit. The first run downloads the model, so it takes longer.

Build an agent

What does an agent look like?

A folder with two Python files, and an optional agent.json:

agent.pytimed, once per task
Looks at the screen, sends actions, and calls done.
init.pyuntimed, before tasks
Installs packages or starts a model server. It may run more than once, so it must be safe to repeat.
agent.jsonoptional
The GPU and the keys the agent needs, for example {"gpu": null, "required_environment_variables": ["MY_API_KEY"]}.

A complete agent.py, apart from your model call:

import sys
from cua_speedrun.client import Computer

computer = Computer(sys.argv[1])
instruction = sys.argv[2]

while True:
    screenshot = computer.observe()["png"]  # PNG bytes
    actions = my_model(instruction, screenshot)  # your code
    if not actions:
        break
    computer.step(actions)

computer.done()

What actions can it send?

step takes a list of actions. Sending several at once saves round trips. Coordinates are screen pixels.

{"mouse": {"left_click": [640, 400]}}
{"mouse": {"double_click": [640, 400]}}
{"mouse": {"right_click": [640, 400]}}
{"mouse": {"move": [640, 400]}}
{"mouse": {"left_click_drag": [[100, 100], [300, 300]]}}
{"mouse": {"scroll": 3}}                  # positive scrolls down
{"keyboard": {"text": "hello"}}
{"keyboard": {"keys": ["ctrl", "s"]}}     # pressed together
{"action": "wait", "time": 1.0}

How do I pass API keys and settings?

Save them with cua-speedrun setup, or export them in your shell. Keys listed in agent.json reach your agent automatically. Pass any other variable with --env NAME.

How do I report model cost?

After each model response, print the task's running total in this format:

__CUA_SPEEDRUN_COST_V1__{"cost_usd": 0.1234}

What can my agent access?

The internet, and the desktop through observe, step, and done. It cannot reset the desktop, open a shell in it, or see how tasks are graded.

Add a benchmark

How do I add my benchmark?

Make a folder with a manifest.yaml and one folder per task. Keep the Gym-Anything environment, with each task's setup and verifier, inside it:

# my-benchmark/manifest.yaml
name: my-benchmark
version: "1"
tasks: [tasks/my-task]

# my-benchmark/tasks/my-task/task.yaml
task_id: my-task
description: The task for the agent to complete.
env:
  kind: gym-anything
  env_dir: ${BENCHMARK_DIR}/environment
  task_id: my-task
cua-speedrun validate --dataset ./my-benchmark
cua-speedrun benchmark --dataset ./my-benchmark --agent claude

To add it to the leaderboard, {{ contact() }}.

Can I run fewer tasks?

Yes. In the code repository, this picks a smaller subset whose scores track the full benchmark, from your past model-by-task scores:

python scripts/select_representative_tasks.py scores.json --output selection.json

Other ways to run

I don't have a Modal account.

Create one at modal.com, then run cua-speedrun setup.

Can I run on my own machine?

Yes, on Linux with KVM:

cua-speedrun benchmark --agent claude --dataset osworld-50 \
  --compute local --environment local

Leaderboard results were measured on Modal, so use Modal to compare with them.

Is there a browser dashboard?

Yes. cua-speedrun dashboard opens one where you can start and inspect evaluations.

Can a script or an AI agent run it?

Yes. Add --json and every command writes JSON records instead of asking questions:

cua-speedrun --json benchmark --agent claude --dataset osworld-50

Results and data

What exactly is timed?

From the moment the agent receives the instruction until it calls done or reaches the time limit. Setup, init.py, and grading are not timed.

How are score and cost calculated?

The score comes from the benchmark's own verifier, averaged over the task set. The cost is the model API cost per task. It does not include Modal compute.

How do I see my results?

cua-speedrun evaluations
cua-speedrun status RUN_ID
cua-speedrun export RUN_ID

export downloads every screenshot, action, and verdict as a zip file.

Where can I get the leaderboard data?

Download the results as a CSV from the leaderboard. Full trajectories are on Hugging Face.

The leaderboard

How do I get my result on the leaderboard?

Run the leaderboard's task sets, then {{ contact() }}. Include the exported zip file and your agent's files.

When something fails

A run failed. What should I check?

cua-speedrun status RUN_ID shows each task's state, and cua-speedrun doctor checks your installation.

Where do I report a bug?

Open an issue on GitHub with the command you ran and the error.
